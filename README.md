# Reech Video Studio plugin

Make social and campaign videos for your brands with Reech Studio: gather context, plan and write, make (previews, render, checks) and learn from results. Everything runs in Reech's cloud through the Reech Studio connector; this plugin holds the instructions Claude follows and the connector's address.

## Install

**claude.ai or Cowork:** Customize → Plugins → Add → Add marketplace → `Reech-Team/reech-studio-plugin` → open **Reech Video Studio** → Add. Then, on the plugin's Connectors tab, connect **Reech Studio** and sign in with the account Reech gave you (email and password, or Google).

**Claude Code:** `/plugin install reech-studio-cloud --marketplace Reech-Team/reech-studio-plugin`, then sign in when the connector asks.

You need a Reech Studio account to use it: organizations and members are created by Reech. Version 0.5.8.
